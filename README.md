# DSA Mastery Guide

A structured DSA (Data Structures & Algorithms) roadmap for C++ interview preparation. Track your progress through 14 phases covering everything from STL basics to Dynamic Programming and Graphs.

## Features

- **14 Phases** — from Foundations to Bit Manipulation & Math
- **226 items** — a mix of concepts to learn and LeetCode problems to solve
- **Progress tracking** — check off items as you go, saved to localStorage
- **Filtering** — view All, To Do, or Completed items
- **Dark mode** — follows your system preference
- **Keyboard accessible** — full tab/enter support
- **Privacy-first** — all data stays in your browser, no backend

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173/dsa-guide/ in your browser.

## Building

```bash
npm run build    # outputs to dist/
npm run preview  # preview the production build
```

## Deploying

Push to `main` and GitHub Actions will deploy to GitHub Pages automatically. Make sure GitHub Pages is set to deploy from "GitHub Actions" in your repo settings.
